# Homework 2 - MVC Project

A small front-end project built with HTML, CSS, and JavaScript using an MVC-style structure.

## Project Overview
- Built to practice separating logic, data, and view concerns.
- Includes app structure, styles, and model files.
- Ready to be extended for additional features or assignments.

## Run Locally
1. Open the project folder in your editor.
2. Start a local server or use a live preview extension.
3. Open the page in the browser.

## Files
- `index.html` - Main page structure
- `app/app.js` - Application logic
- `model/model.js` - Data/model layer
- `css/styles.css` - Styling
- `scss/` - SCSS source files
